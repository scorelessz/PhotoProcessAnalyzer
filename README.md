# PhotoProcessAnalyzer · 照片处理工具（macOS 原生复刻版）

一个用 **Swift + SwiftUI** 编写的 macOS 原生应用，完整复刻 Windows 版「照片处理工具.exe」（`PhotoProcess 1.0.0.25`，人社部人事考试中心的报名证件照预处理工具）的核心处理逻辑，并内置了该程序的**逆向工程分析报告**。

> 通过 [REA](https://github.com/morluto/rea) + Ghidra 12.1.4 对原程序做静态逆向分析，还原了校验/裁剪/压缩流水线与硬编码常量。本仓库的「照片处理」功能即按这些逆向成果重新实现。

## 功能

应用菜单分两级：**一级菜单**为「照片处理」「关于本应用」；**二级菜单「专业信息」**收纳逆向分析相关内容（概览 / 逆向分析报告 / 消息映射与常量 / 资源文件）。

### 1. 照片处理（核心）
按原 exe 逻辑处理报名证件照：

1. 校验 JPEG（前 2 字节 `FF D8`）
2. 尺寸检查：宽 ≥ 295、高 ≥ 413
3. 人脸检测（macOS 原生 Vision 框架，替代原 OpenCV 1.0 Haar 分类器），取最大人脸
4. 要求 人脸宽 / 图宽 ≥ **0.32**
5. 背景检查：3 个 3×3 采样点 → RGB→HSV → 判定白/蓝/红，三块须一致
6. 黄金比扩框：`裁剪框宽 = trunc(脸宽 × 1.6181229773462784)`，`裁剪框高 = round(宽 × 413/295)`
7. 留白比例校验（`ratio_x` / `ratio_y` ∈ [0, 0.5]）
8. 缩放至 **295 × 413**
9. 保存时以 **质量 40** 压缩（约 10 KB），并追加 10 字节标记 `FF 02 00 08 "gjgwy2"`（原程序用于报名网站识别的固定尾部）

### 2. 逆向分析报告
内置主报告与补充报告：构建环境、`photo.ini` 语义、校验流水线、错误码映射、保存流水线、MFC 消息映射表、控件 ID ↔ 处理函数、`ftol` 扩框常量等。

### 3. 资源查看
从原 exe 的 `.rsrc` 节提取的 21 个资源（13 位图、3 图标、对话框、字符串表、版本信息）的清单与位图/图标预览。

## 构建

需要 macOS 14+ 与 Xcode 命令行工具（`swift`）。

```bash
./build.sh          # 编译通用二进制 (arm64 + x86_64)，签名并打包成 .dmg
```

产物：`PhotoProcessAnalyzer.dmg`（双击挂载，把 `PhotoProcessAnalyzer.app` 拖入「应用程序」）。

也可以在 Xcode 中打开 `Package.swift` 直接运行。

## 使用

打开应用后，左侧选择「照片处理」：

1. 点击 **打开照片文件**，选择一张 JPG 证件照
2. 符合要求时，右侧显示裁剪缩放后的 295×413 预览
3. 点击 **保存照片文件**（默认文件名 `报名照片.jpg`）

不符合要求时，会按原程序的措辞提示（非 JPG、像素数低、背景不符合、头部比例不符合、非正面人像）。

## 逆向工程结论摘要

| 项 | 结论 |
|---|---|
| 目标 | `照片处理工具.exe`，PE32/i386，SHA-256 `e344fc1b…` |
| 构建 | MFC 4.2 + MSVC6 + OpenCV 1.0，Debug 构建 |
| 阈值 | `photo.ini` 16 键，内置默认值硬编码 |
| 扩框系数 | `1.6181229773462784`（≈黄金比 φ）+ `413/295` 高比 |
| 输出 | 295×413，JPEG 质量 40，尾部 `FF 02 00 08 gjgwy2` |

详见仓库内嵌的完整报告（应用内「逆向分析报告」页）。
