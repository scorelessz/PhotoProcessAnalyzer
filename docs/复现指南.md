# 逆向分析复现指南

本指南记录从零复现「照片处理工具.exe」逆向分析的全过程。使用 [REA](https://github.com/morluto/rea)（MCP 服务，rea-agents 6.8.0）驱动 **Ghidra 12.1.4** 完成。

> 环境：macOS（arm64），Xcode 27.2 自带 JDK 21；目标文件与 OpenCV 1.0 / MFC42 依赖 DLL 同目录。

## 0. 目标

- 文件：`照片处理工具.exe`，PE32 / i386 / GUI，镜像基址 `0x400000`
- SHA-256：`e344fc1b4619d355d88a52bc1eddf216cca60fb55c8e9bab42ac5d4ed04183a9`

## 1. 打开目标并获取概览

```
open_binary <照片处理工具.exe>
binary_overview
```

结果：6 个段（`.text` 0x401000–0x599000，`.rdata` 0x599000–0x5d2000，`.data` 0x5d2000–0x5e140c，`.rsrc` 0x5e2000–0xd87000），3843 个函数，2888 个字符串。

## 2. 识别运行环境（导入表）

```
inspect_pe_imports <exe>
```

关键结论：`MFC42.DLL`（纯序号，旧 MFC 4.x）、`MSVCRT.dll` + **`MSVCRTD.dll`**（Debug CRT）、OpenCV **1.0**（`cv100/cxcore100/highgui100/ml100`）、`WS2_32`。据此判断为「MFC + MSVC6 + OpenCV 1.0 的 Debug 构建」。

| 串地址 | 文案 |
|---|---|
| `0x5d2124` | 打开照片文件不符合要求。请选择正面人像标准证件照片文件。 |
| `0x5d2160` | 头部比例不符合要求 |
| `0x5d21a4` | 背景不符合要求 |
| `0x5d21e0` | 像素数低 |
| `0x5d2220` | 类型不是JPG/JPEG格式 |
| `0x5d22ec` | 照片已保存成功，是否退出 |

## 4. 交叉引用 → 定位核心函数

```
xrefs 0x5d2124        # → 0x402f09（位于 0x402c10 内）
resolve_containing_procedure 0x402f09
procedure_pseudo_code 0x402c10
```

按「字符串地址 → xrefs → 所在函数 → 反编译」逐步还原出应用代码（集中在 `0x401000–0x403200`）：

| 函数 | 作用 |
|---|---|
| `0x401000` | 背景色分类（白/蓝红/其它） |
| `0x401070` | 3 个 3×3 采样点 → RGB→HSV → 逐块分类 |
| `0x4013a0` | 核心校验+裁剪：读 ini、尺寸、背景、人脸、黄金比扩框、缩放 |
| `0x401d60` | 打开流程调度：JPEG 魔数 → cvLoadImage → 0x4013a0 |
| `0x401e10` | 在 JPEG 末尾追加 10 字节标记 |
| `0x401e90` | 读前 2 字节判 `FFD8` |
| `0x401f10` | CImage(GDI+) 以 quality=40 重编码 |
| `0x4024d0` | 资源位图写出为 .bmp |
| `0x402c10` | 「打开照片文件」按钮处理 |
| `0x403010` | 「保存照片文件」按钮处理 |

## 5. 还原 10 字节标记

```
procedure_assembly 0x401e10
```

`fwrite` 逐字节写入的常量：

```
FF 02 00 08 67 6A 67 77 79 32   ("gjgwy2")
```

（`ev_ddd40d8e…`，汇编 `MOV BYTE PTR [ESP+…], 0xFF/0x02/0x00/0x08/'g'/'j'/'g'/'w'/'y'/'2'`）

## 6. 还原 `ftol` 扩框常量

```
procedure_assembly 0x4013a0
```

x87 序列：`FILD 脸宽 → FMUL [0x599538] → _ftol`（宽度）；`FILD … → FADD [0x599518] → _ftol`（高度）。读 `.rdata` 双精度：

| 地址 | 值 | 含义 |
|---|---|---|
| `0x599540` | 0.32 | 人脸宽/图宽阈值 |
| `0x599538` | 1.6181229773462784 | 横向扩框系数 ≈ φ |
| `0x599530` / `0x599528` | 0.9 / 1.1 | 宽高比校正界 |
| `0x599518` | 0.5 | 高度四舍五入常数 |

## 7. 还原 MFC 消息映射与控件映射

1. 扫描构造函数 `mov [ecx], <vtable>`（`C7 01 imm32`）→ 主对话框 vtable `0x5997c0`（构造函数 `0x4023df`）。
2. 扫描 `mov eax, <map>; ret` → `GetMessageMap() = 0x4024c0` → AFX_MSGMAP `0x599650` → 条目表 `0x599658`。
3. `address_name 0x44128e` → `MFC42.DLL::CDialog::DoModal`（vtable 第 48 槽）做锚点。
4. 解析 `DIALOG_id102`（DLGTEMPLATEEX）得到控件 ID 与标题。

结论：

| 按钮 | ID | 处理函数 |
|---|---|---|
| 打开照片文件 | 1 (IDOK) | OnOK 重写 = `0x402c10` |
| 保存照片文件 | 3 | `0x403010` |
| 退出操作 | 2 (IDCANCEL) | 默认 `CDialog::OnCancel` |
